## 💻 Hasil Eksekusi Program

Praktikum ini dikerjakan menggunakan Jupyter Notebook (`.ipynb`). Berikut adalah tiga bagian utama yang telah dieksekusi dan dianalisis:

### A. Percabangan (Conditionals)
Program telah berhasil menjalankan logika evaluasi menggunakan `if`, `elif`, dan `else`. 
* Pengecekan dilakukan menggunakan operator komparasi (`<`, `>`, `==`) dan operator logika (`and`).
* **Output:** Program mampu menyortir input pengguna untuk menentukan kriteria kelayakan lamaran kerja dan mengklasifikasikan suhu lingkungan.

### B. Perulangan (Loops)
Praktikum ini menerapkan dua jenis perulangan:
* **For Loop:** Digunakan untuk membaca dan menampilkan isi dari *List, Tuple, Set,* dan *Dictionary*. Selain itu, berhasil diimplementasikan untuk membentuk deret pola bintang (*nested loop*).
* **While Loop:** Digunakan untuk menjalankan instruksi berulang yang bergantung pada suatu kondisi batas (misalnya, terus meminta input hingga pengguna mengetik jawaban tertentu).

### C. Fungsi (Functions)
Penulisan kode dibuat lebih rapi dengan memanfaatkan fungsi:
* **Fungsi Def:** Pembuatan *tools* pengecekan batas nilai siswa.
* **Fungsi Lambda:** Pembuatan fungsi anonim untuk perhitungan aritmatika sederhana yang lebih efisien secara penulisan dibandingkan fungsi reguler.
